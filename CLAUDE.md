# Convenciones del proyecto (Leer para Todos)

Contexto: app web de fomento lector con pictogramas SAAC para el Liceo Piedra Azul. Prioridad: accesibilidad (WCAG 2.1 AA) y bajo estímulo visual. Ver `README.md` y `docs/`.

## Estructura
- `frontend/`: React + Vite + TypeScript.
- `backend/`: Laravel 12 + PostgreSQL.
- `docs/`: decisiones y modelo de datos.

## Ramas
- `main` (estable) y `develop` (integración): sin commits directos, solo PR con 1 aprobación.
- Trabajo en `feature/PLPA-n-descripcion` o `fix/PLPA-n-descripcion`, desde `develop`.
- `prototipo`: congelada, solo referencia. No se mergea.

## Commits
- Conventional Commits con clave Jira obligatoria: `feat(PLPA-12): descripción`.
- Tipos: `feat`, `fix`, `docs`, `refactor`, `test`, `chore`. Lo valida commitlint.
- Mensajes sin firmas ni trailers de IA (nada de `Co-Authored-By` ni "Generated by").

## Reglas
- Ninguna historia se cierra sin sus tests.
- Sin secretos ni datos reales de estudiantes en el repositorio.
- Datos de menores mínimos (sin RUT, sin fecha de nacimiento); códigos de acceso solo como hash.
- Todo pictograma e imagen lleva texto alternativo.
- Cambios no triviales: proponer opciones antes de implementar.
